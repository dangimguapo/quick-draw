# Quick Draw 8-bit character prompt set

Generated with the built-in image generation workflow.

## Shared specification

Create one centered, full-body playable mobile-game character in authentic
late-1980s NES pixel art. Use hard square pixels, enlarged 48×64-sprite
proportions, a maximum of four character colors plus a dark outline, generous
padding, and a clear all-ages silhouette. No antialiasing, gradients, soft
shading, cast shadow, text, logo, watermark, scenery, frame, UI, cropping, or
extra characters. Render on a perfectly flat chroma-key background for local
transparency removal.
